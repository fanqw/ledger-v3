# Proposal: order-detail-summary-bar

## Summary

订单详情页明细区三项视觉/信息增强：

1. **「明细列表」单独占一行**：标题与操作按钮分离，标题独立成行更醒目
2. **表格列分隔线**：明细表格增加列间竖线；**每一大类（分类分组）之间的分割线更明显**，分组边界一眼可辨
3. **表头总结栏**：在表格上方（表头位置）新增分类汇总栏，逐分类展示「分类名 + 商品种数 + 分类金额」，最后「共计总金额」，样式经 frontend-design 优化

纯前端改动，仅涉及 `apps/web/src/pages/OrderDetail.tsx` 与 `apps/web/src/index.css`，不动后端/共享层。

## Motivation

当前订单详情明细表格存在三个可读性问题：

- 「明细列表」标题与「导出 Excel / 添加明细」按钮挤在同一行，标题不够醒目
- antd 表格默认只有行分隔线、没有列竖线，列与列边界模糊；分类分组（rowSpan 合并）之间仅靠分类列文字区分，多个大类堆叠时看不出分组边界
- 分类小计信息分散在表格「分类金额」合并列与底部总计行中，缺少一个一眼可读的分类汇总区

## Scope

### In Scope
- 明细列表标题独立成行，操作按钮移至标题下方一行
- 明细表格加列竖线；分类分组边界加粗分隔线（首行整行顶边框加粗 + 暗色）
- 表格上方新增分类总结栏：每个分类一块（分类名、商品种数、分类金额），末尾「共计」总金额
- 明暗主题适配，金额/数量用 tabular-nums 等宽数字

### Out of Scope
- 后端/数据层改动（分组、小计逻辑前端已有 `groupItems`）
- Excel 导出格式调整
- 移动端明细表格（桌面表格在 ≤991px 隐藏）

## Glossary
- 分类分组：按商品分类聚合的明细子集（`groupItems` 输出）
- 商品种数：某分类下**不同商品数**（按 commodityId 去重），单位「种」
- 分类金额：某分类下所有明细 lineTotal 之和
- 总结栏：表格表头上方的分类汇总条，逐分类展示，末尾共计
