## Why

当前系统已完成 Ant Design 迁移，但应用壳、页面标题、筛选区、表格、表单和响应式行为仍由各页面分别组织，导致视觉层级不一致、主操作入口分散，并且手机端的宽表格难以使用。现在需要在不改变业务逻辑和后端接口的前提下建立统一、桌面优先且可响应式降级的工作区体验。

## What Changes

- 将工作区统一为经典蓝品牌下的轻量专业视觉方向，使用窄侧栏、低噪声顶栏和最大化的主工作区。
- 建立统一页面结构：页面标题与说明、页级主操作、筛选工具栏、主数据区和分页。
- 统一列表、表格、表单弹窗、操作菜单、加载、空数据和错误状态的视觉与交互规则。
- 将新增操作从悬浮按钮移至页面标题区，提升发现性并统一操作位置。
- 提供桌面、平板和手机三档响应式行为：平板隐藏低优先级信息；手机使用抽屉导航并将宽表格降级为摘要条目。
- 改善键盘焦点、图标按钮标签、颜色对比和可点击目标等可访问性细节。
- 保留现有业务请求、数据结构、校验、权限、ECharts 图表和 Ant Design 组件库，不新增后端能力。

## Capabilities

### New Capabilities

- `responsive-data-workspace`: 统一业务页面的信息层级、数据呈现、操作状态和桌面/平板/手机响应式行为。

### Modified Capabilities

- `workspace-navigation`: 将现有工作区导航调整为桌面默认窄侧栏、平板可用、手机抽屉导航，并明确应用壳的可访问性与状态持久化行为。

## Impact

- 主要影响 `apps/web/src/components/layout/`、`apps/web/src/pages/`、`apps/web/src/index.css`、应用级 Ant Design 主题配置及相关前端测试。
- 可能新增少量面向页面布局和响应式数据呈现的共享前端组件；不引入新的 UI 依赖。
- 后端 API、数据库、共享 Zod schema、认证流程和业务规则不变。
- 需要更新现有前端 E2E/视觉验收，覆盖桌面、平板和手机视口。
