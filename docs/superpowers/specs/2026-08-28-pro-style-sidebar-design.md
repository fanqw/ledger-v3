# Ant Design Pro 风格菜单栏设计

## 目标

参考用户提供的 Ant Design Pro 截图重构工作区菜单栏。桌面端重点还原清晰的品牌顶栏、可展开的层级菜单和侧栏边界折叠控制；平板与手机继续使用抽屉导航，避免压缩业务内容。

## 布局结构

- 顶部品牌栏跨越整个应用宽度，高度保持 56px，左侧显示系统标识和“台帐系统”，右侧保留主题与账户操作。
- 顶栏下方为侧栏和主内容区。桌面侧栏展开宽度为 220px，折叠宽度为 64px。
- 主内容区继续显示面包屑和当前页面，不改变业务页面、路由或数据请求。
- 小于 992px 时不渲染桌面侧栏，使用现有抽屉导航。

## 菜单层级

- “仪表台”和“数据分析”为一级直达菜单。
- “订单管理”为可展开子菜单，包含“订单列表”。
- “物料管理”为可展开子菜单，包含“商品分类”“商品单位”“商品信息”“进货地”。
- 当前路由对应的菜单项保持选中，其所属父菜单自动展开。
- 用户手动展开或收起父菜单后，正常遵循 Ant Design Menu 的层级交互。

## 侧栏展开与收起

- 桌面首次进入默认展开。
- 折叠触发器位于侧栏右边界靠近顶部的位置，呈白色圆形按钮，带细边框和轻阴影。
- 展开时显示向左箭头，折叠时显示向右箭头；按钮提供明确的 `aria-label`。
- 折叠时只保留菜单图标，使用 Tooltip 提供菜单名称；子菜单以浮层方式访问。
- 展开状态写入 `ledger:sidebar-collapsed`，刷新后恢复用户选择。
- 宽度变化使用短促过渡，并遵循 `prefers-reduced-motion`。

## 视觉细节

- 侧栏使用应用表面色和右侧细分隔线，不使用大面积强调背景。
- 选中项使用浅蓝背景、品牌蓝图标与文字；普通项保持中性灰。
- 菜单区域与折叠按钮保持足够触控面积，按钮不会覆盖菜单文字或主内容。
- 暗色主题继续使用既有设计 token，边框、阴影和选中态提供对应暗色表现。

## 响应式行为

- `>= 992px`：显示可折叠桌面侧栏和边界触发器。
- `< 992px`：隐藏桌面侧栏与触发器，顶栏菜单按钮打开 280px 抽屉。
- 抽屉中始终显示完整菜单文字和层级，不读取桌面折叠状态。

## 验证

- 契约测试覆盖默认展开、220/64px 宽度、边界触发器、状态持久化和真实子菜单。
- 无头浏览器分别验证展开、折叠、刷新保持、子菜单导航和抽屉导航。
- 在 1440×900、1024×768、768×1024、390×844 视口保存对照截图并检查页面级横向溢出。
- 运行 Web 测试、构建和 lint，确保业务页面没有回归。

## 非目标

- 不复制参考截图中的示例页面、右侧设置按钮或第三方品牌。
- 不改变现有路由、权限、主题切换、账户菜单或业务数据结构。
