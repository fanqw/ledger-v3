# 部署文档

## 一、Docker Compose 一键部署

### 前置条件

- Docker 20+ / Docker Compose v2+
- `JWT_SECRET`、`JWT_REFRESH_SECRET` 环境变量（安全密钥）

### 部署步骤

```bash
# 1. 构建后端 dist（server Dockerfile 依赖编译产物）
pnpm --filter server build

# 2. 配置环境变量
export JWT_SECRET=your-jwt-secret
export JWT_REFRESH_SECRET=your-refresh-secret

# 3. 一键启动
docker compose up -d
```

### 服务清单

| 服务 | 容器 | 端口 | 说明 |
|------|------|------|------|
| frontend | ledger-v3-frontend | 80 | Nginx 托管前端 + /api 代理 |
| server | ledger-v3-server | 3001 | NestJS API |
| postgres | ledger-v3-postgres | 5432 | PostgreSQL 16 |
| redis | ledger-v3-redis | 6379 | Redis 7 |

### 验证

```bash
# 前端页面
curl http://localhost            # 应返回登录页 HTML

# 健康检查
curl http://localhost/api/health
# {"success":true,"data":{"db":"connected","redis":"connected","uptime":...}}

# Swagger
open http://localhost/api/docs
```

### 停止与清理

```bash
docker compose down          # 停止（保留数据卷）
docker compose down -v       # 停止并删除数据卷
```

## 二、环境变量

| 变量 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `DATABASE_URL` | 是（compose 已设） | - | PostgreSQL 连接串 |
| `REDIS_HOST` / `REDIS_PORT` | 是（compose 已设） | - | Redis 地址 |
| `JWT_SECRET` | 是 | - | Access Token 密钥 |
| `JWT_REFRESH_SECRET` | 是 | - | Refresh Token 密钥 |
| `PORT` | 否 | 3001 | 后端端口 |

> compose 中 `DATABASE_URL`/`REDIS_HOST`/`REDIS_PORT` 已指向容器内服务，`JWT_*` 需通过 shell 环境变量注入。

## 三、常见问题

### 后端启动失败：Prisma 未生成

```bash
pnpm --filter server db:generate
```

### compose up 后前端 502

- 检查 server 是否健康：`docker compose logs server`
- 确认 `JWT_SECRET` 已设置（缺失会导致 server 启动失败）

### 数据库迁移

```bash
pnpm --filter server db:migrate
```

### 创建用户

```bash
pnpm --filter server db:create-user --username xxx --password xxx --role admin
```

## 四、本地开发部署

不依赖 Docker 的本地开发：

```bash
pnpm install
pnpm dev    # 前端 5173 + 后端 3001
```

需要本地 PostgreSQL + Redis 运行（或用 `docker compose up postgres redis` 仅启动依赖）。
